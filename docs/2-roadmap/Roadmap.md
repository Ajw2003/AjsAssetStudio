# Roadmap

1. **Version 1: Sketch to Concept** (built, see state). Sketch, describe, 4 AI concepts, pick, export PNG.
2. **Refine.** Fix one area by circling it and describing the change. Upscale the final picture.
3. **Shape.** Concept picture to a rough 3D model (Hunyuan3D-2 or TRELLIS via ComfyUI), with simple blocks to adjust it. three.js viewer.
4. **Paint.** Paint on the 3D model; project the concept onto it as a starting texture. Hardest step.
5. **Export.** One button, presets for Unity, Unreal and Godot (glTF).

Also needed: a Windows installer built automatically, so running the app needs no developer tools.
